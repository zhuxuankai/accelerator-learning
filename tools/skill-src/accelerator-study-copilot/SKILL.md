# 加速器学习驾驶舱

服务于"加速器学习驾驶舱"工作区，也就是该技能的部署仓库根目录
（例如 `C:\path\to\academic learning`，以实际 clone 位置为准）。

## 工作区约定

语料只有两类，**不要**读取或引用工作区以外的任何目录（文件夹名以 `kb/config.json` 的
`include_dirs` 为准）：

1. 课程目录：`kb/config.json` 里 `include_dirs` 列出的那几个（课件放这里）；
2. 联网下载的论文：`文献/`。

`kb/`（索引与中间产物）、`tools/`（脚本）、`学习路线/`（路线与看板）是产物目录，不是语料。

## 命令（在工作区根目录执行）

入口统一是 `tools/run.ps1`；`python` / `node` 都不在 PATH，不要绕开这个入口。

- 检索：`run.ps1 query "<问题>" [-Course <目录>] [-Kind slide|book|paper|doc] [-K 8] [-AllVersions] [-FullText]`
- 增量入库：`run.ps1 ingest`（加 `-Full` 全量重建）
- 论文语料：`run.ps1 papers [-Write]`（默认只出候选清单）
- 每周维护：`run.ps1 weekly`（入库 → 覆盖度 → 看板 → 下周计划）
- 状态：`run.ps1 status`
- 检索回归：`run.ps1 eval 3`（看 top-3 命中率）

## 回答课程问题的固定动作

1. 先检索，可用 `-Course` 限定课程提高精度。
2. 用自己的话讲解，并给出处：`文件名 + 页/张`（例如"束线光学/1-3 X射线及其与物质的相互作用-0929.pdf 页9"）。
3. 检索为空就说"课件里没有"，再按物理常识讲解，并明确区分"课件内容"与"我的补充"。
4. 扫描版课件的公式在 OCR 里是乱码，不要伪造引用；公式类问题直接讲原理。
5. 中文回答，专业术语保留英文，公式用 LaTeX 行内写法。
6. 一次讲不清时，给出"下一步该看哪一页"的指路，而不是堆砌全部检索结果。

## 每周维护流程

1. 在工作区根目录跑 `tools/run.ps1 weekly`。
2. 读 `学习路线/覆盖度.md` 与生成的 `学习路线/周计划/<日期>.md`。
3. 告诉用户四件事：本周新增了什么语料、下周读哪两篇论文（1 精读 + 1 泛读）、下周做哪个仿真任务、哪一处课程薄弱点该补。
4. 无新语料、无逾期、无待确认项时保持静默，不要为了汇报而汇报。

## 进度纪律

`学习路线/进度追踪.csv` 每行都有 `来源` 字段：

- `已确认`：用户明确说过，或以作业/代码/产出为证。
- `推断`：系统推测。

**永远不要擅自把 `推断` 改成已完成**，只把它们列成待确认清单。

## 与其他 skill 的分工

- 文献综述、系统性检索 → `deep-research`
- 读书笔记、报告、论文写作 → `academic-paper`
- 对自己写的材料做审稿式挑刺 → `academic-paper-reviewer`
- 端到端研究流水线 → `academic-pipeline`
- 组会幻灯片 → `ppt-master-skill`

## 环境提示

联网（抓论文、下载 OCR 语言包）需要用户授权；索引建好后日常答疑完全离线可用。
大体积中间产物写在 `%TEMP%\acc_kb_render`，可交付物留在工作区。
